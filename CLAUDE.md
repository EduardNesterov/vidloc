## Что это

Vidloc — локальный десктопный локализатор видео для macOS (Apple Silicon).
Перевод EN/RU/IT → украинский: субтитры и озвучка; в работе — удаление вотермарок и вшитых
субтитров. Всё работает офлайн, без отправки данных в сеть.

## Текущий статус

- **Phase 1** (распознавание → перевод → субтитры): готово, протестировано end-to-end.
- **Phase 1b** (озвучка/дубляж: XTTS-v2 / Piper / ukrainian-tts): в работе.
- **Phase 2** (удаление вотермарок / вшитых субтитров): работает в GUI как **пошаговый мастер**:
  - workspace-кэш (`vidloc/workspace.py`): скачанный исходник + ASR-транскрипт по моделям →
    повтор того же видео не качает/не распознаёт заново.
  - распознавание — отдельный шаг (выбор модели → «Розпізнати» с busy-баром → исчезает;
    есть «Пропустити»).
  - удаление — **per-region, time-gated**: `TimedRegion` (rect + интервалы); редактор
    рамок+времени `vidloc/gui/region_editor.py` (до 15 рамок, ресайз/удаление ×, таймлайн
    со скобками, скраб-превью). Затирание (LaMa) идёт **только в размеченные интервалы**.
  - Всё закоммичено на `42e4093` (+ `b5b7367`). Коммиты **локальные**, на GitHub не уходили.

## Где мы остановились — следующий шаг: reuse-first ускорение удаления

**Спроектировано, в код НЕ встроено** (вся проработка была в /tmp, проекта не касалась).

**Проблема:** профилировка инпейнта — **LaMa ≈ 94%** времени (декод/энкод/склейка ≈ 6%).
Имеет смысл сокращать только **число запусков LaMa**, а не ускорять её саму.

**Идея (подтверждена замерами на сырых `work/downloads/`):** видео темпорально избыточно —
фон за вотермаркой почти всегда виден в соседних кадрах. Статичный угол-лого пропускается
**95–100%** дешёвым warp-reuse; для **временных** субтитров чистый фон почти всегда рядом →
потенциально **~0 LaMa**. Сильно зависит от контента.

**Урок прототипа (важно):** авто-детекция «что и когда убирать» — хрупкая (по яркости
недодетектит, по residual передетектит + произвольная motion-comp даёт артефакты).
**НЕ авто-детектить** — вести движок от **разметки пользователя** (Phase-3: регион + интервалы).

**Что строить в `vidloc/inpaint/lama_worker.py` (v1, безопасно):**
1. `clean_plate` — чистый кроп фона; обновляется из кадров, где маска ПУСТА (вне интервалов).
2. Кадр внутри интервала: есть `clean_plate` → сверить его с текущим кропом **на немаскированной
   PAD-рамке**; остаток мал → заполнить маску из плиты (без LaMa); велик → LaMa. Плиты нет →
   LaMa + засеять плиту результатом.
3. **Без motion-comp в v1** — валидация по рамке это «предохранитель» от артефактов.
   Motion-comp / гомография — v2, когда v1 докажет чистоту.
4. Кейфрейм-рефреш раз в N кадров (против дрейфа). cv2 (OpenCV 4.11) **уже есть в `.venv-inpaint`**.
5. Проверять через GUI: разметить на `work/downloads/For Test.mp4` нижнюю полосу субтитров +
   интервалы → смотреть счётчик LaMa и картинку.

**Отложено в `stash@{0}`:** эксперимент «1-3» (аппаратный VideoToolbox декод/энкод + полнокадровый
пайп). **Откачен:** полнокадровый сырой пайп через ядро вызвал скачок `kernel_task` и лаги UI.
Как есть не восстанавливать; только lever-3 (VT-энкод) можно вернуть отдельно и аккуратно.

**Конвенция по коммитам:** коммитим **локально**; `git push` — только по явной просьбе.

## Как запускать

- GUI: `./run.sh` (PySide6).
- CLI: `PYTHONPATH=. .venv/bin/python -m vidloc.cli input.mp4 --source en --mode subtitles --subs soft`
- Полный список флагов CLI — в `README.md`.

## Окружение

- Зависимости: `uv` (Python 3.11; см. `.python-version`, `pyproject.toml`, `uv.lock`).
- Ускорение: Apple Silicon MPS/Metal (mlx-whisper для ASR, torch MPS для NLLB-200).
- `ffmpeg`/`ffprobe` лежат в `bin/` — в git НЕ входят (см. README, как получить).
- Модели — в `models/` (~26 ГБ), в git НЕ входят, тянутся автоматически при первом запуске.

## Несколько venv — это намеренно

В проекте 5 окружений: `.venv` (ядро) + `.venv-tts`, `.venv-uktts`, `.venv-piper`,
`.venv-inpaint`. Движки озвучки и inpainting конфликтуют по зависимостям с ядром и между
собой, поэтому вынесены в отдельные venv. Все они в `.gitignore`.

**Известный пробел:** создание вспомогательных venv пока не заскриптовано и не описано —
задокументировать/сделать скрипт до того, как делиться репозиторием с кем-то.

## Если соберёшься делать репозиторий публичным

Проект сильнее всего смотрится как «движок локализации видео» (ASR → перевод → TTS → ffmpeg) —
это и стоит показывать в портфолио. Функцию удаления вотермарок лучше не выносить в публичную
витрину (вопросы авторских прав). Перед публикацией проверить лицензии шрифтов в `assets/`.
